## 机房怎么放，取决于你的买家在哪

## 1G 内存到底够不够

行业里比较通行的判断是这样：轻量 WordPress 配 Nginx 加缓存插件，1GB 内存能跑；插件装到十几个、或者同一台机器上放两三个站，升到 2GB，避免内存溢出把站点搞挂。

WordPress 加 WooCommerce 真正吃的是内存和磁盘 IO，CPU 一般不是瓶颈。日均一两千 PV 的优化站点，2GB 内存加双核足够；只有大促、多语言、插件堆了一大堆的情况才需要往 4GB 以上走。硬盘同理，标准站加几百张产品图，20–40GB 就够，超大原图应该丢 CDN 或对象存储，别堆在 VPS 本地。

JustHost 全系用 NVMe，磁盘 IO 这一块不用担心，比 SATA SSD 快一个档次。所以选档位的判断可以简化成一条：**看内存，不看 CPU**。

一个纯展示站、十个产品页、每天几十个询盘，Sirius 的 1GB 完全撑得住。开始上 WooCommerce、装支付插件、物流查询插件、多语言插件，直接跳到 Arcturus 的 2GB，别在 1GB 上硬扛。

## 下单前要确认的几件事

**要不要备案。** 境外服务器部署网站不需要工信部备案，买完直接上线。国内服务器才要走备案流程，这是两类产品最本质的区别之一。

**怎么付款。** 支持支付宝、PayPal、银联和 USDT。国内用户直接支付宝，没有障碍。

**流量超了会怎样。** 官网写的是不限流量、端口 300Mbps 公平共享，标注相当于每月 93TB 以上。跑满端口会被限速，不会停机断网，也不会产生超额账单。外贸站正常流量离这个量级很远。

**有没有自动备份。** 没有。官网 FAQ 明确写了不提供自动备份，建议自己搭一个备份服务器存副本。这条对外贸站挺关键，订单数据丢了没法补，开通后第一件事就是把定时备份配上。

**能不能换 IP。** 可以在用户中心自助更换，官网把它列为所有套餐的标配功能。

**能不能升配。** 可以，加 CPU、加内存、加磁盘都不用迁移数据，停机时间很短。所以起步买小一点、跑起来再升，是可行路线。

**登录方式。** 官网写的是支持 SSH 访问，可以复制编辑文件、用 git、跑 bash 脚本。是否强制密钥登录、密钥是否只能下载一次，资料里没写清，开通时留意控制台提示。

## 常见问题

**外贸独立站服务器需要备案吗？**

不需要。境外机房部署的网站不走工信部备案流程，买完配置好环境就能上线。需要备案的是国内服务器。

**1G 内存跑 WooCommerce 够吗？**

产品少、插件少可以，但余量很小。WooCommerce 本身加上支付、物流、多语言几个插件，内存占用会明显上去，建议直接选 2GB 的 Arcturus，一年多花一百多块，省掉半夜站点挂掉的麻烦。

**原生 IP 对 Google 排名有直接帮助吗？**

直接作用不大。排名主要看内容质量和 Core Web Vitals 这类页面性能指标。原生 IP 的实际价值在别处：降低 Stripe、Facebook 广告账户这类平台的风控概率。做投放、收款的外贸站值得为它多花钱，纯展示站无所谓。

**JustHost 适合国内团队天天登后台吗？**

看你对"卡"的容忍度。它不是中国方向优化线路，国内访问的延迟和晚高峰稳定性比不过专做 CN2 GIA 的商家。日常传图、改价格这类操作能做，但要指望秒开，得加预算换方向。

**VPS Promo 便宜，能拿来建站吗？**

不建议。512MB 内存、10Mbps 端口、邮件端口被限制，跑不动正常的 WordPress 站。
